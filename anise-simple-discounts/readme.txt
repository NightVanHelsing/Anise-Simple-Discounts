Assign permanent percentage discounts to individual WooCommerce customers.

== Description ==

Anise Simple Discounts allows store administrators to assign a permanent percentage discount to individual WooCommerce customers directly from the user profile page.

== Installation ==

1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin.
3. Edit a user profile and set the discount percentage.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and activated.

= How do I assign a discount? =

Edit a user's profile and enter a value between 1 and 99.

= How do I delete assigned discounts? =

When disabling the plugin, you will have the option to delete all assigned discounts.
